## 四、导入步骤

1. 控制台「知识库」按上表新建各库。
2. 上传对应 `.md` 文件。
3. 分块参数：
   - 大小 300–500 字
   - 重叠 50 字
   - 按标题切分（`##` 已是分节点）
   - 混合检索
4. Agent 绑定这些知识库。
5. 验证召回：
   - "履卦的卦辞是什么？" → `yijing-classics`
   - "梅花易数怎么定体卦和用卦？" → `meihua-classics`
   - "增删卜易怎么取用神？" → `liuyao-classics`
   - "滴天髓怎么论甲木？" → `bazi-classics`
   - "烟波钓叟歌怎么讲阴阳二遁？" → `qimen-classics`
